# LUNEL Map Cover ♾️

Windows向けの、OBS Studio用ミニマップカバー補助ツールです。VALORANT配信時に任意のPNGをミニマップ上に重ね、マウスの水平移動に合わせて画像を回転させます。

> 非公式の配信補助ツールです。Riot GamesおよびOBS Studioの公式製品・公認製品ではありません。

## 主な機能

- OBSブラウザソースでPNG画像を表示
- マウスの水平移動に連動した画像回転
- 360°キャリブレーション
- 画像サイズ、回転倍率、回転方向の調整
- PNG画像の差し替え
- ダーク×ラベンダー／ホワイト×ピンクのテーマ
- OBS起動・終了との連携
- 小さい画面向けのスクロール操作

## 動作環境

- Windows PC
- OBS Studio（別途インストールが必要）
- 配布版の利用にPythonのインストールは通常不要

## ダウンロードと導入

1. [Releases](../../releases) の最新版から `LUNEL-MapCover-v1.0.zip` をダウンロードします。
2. ZIPを**すべて展開**し、フォルダごと保存します。
3. `LUNELControl.exe` を起動します。
4. 「OBS とマップ隠しを起動」を押します。
5. OBSの「ソース」→「＋」→「ブラウザ」を追加し、URLに以下を設定します。

   `http://127.0.0.1:8766/overlay.html`

6. OBSのプレビューで画像をミニマップに重ね、サイズを調整します。

## 360°キャリブレーション

VALORANTの射撃場などで「360°キャリブレーション開始」を押し、4秒以内にゲームへ戻ります。続く10秒間に水平に一方向へ正確に360°回転して静止してください。測定後は表示を確認し、必要なら再調整します。

## 終了方法

- OBSを終了するとマップ隠しだけ自動停止し、LUNELの操作画面は残ります。
- LUNELの「×」でアプリとマップ隠しを終了します。OBSは終了しません。

## 表示されないとき

- アプリでマップ隠しを開始しているか確認
- OBSのブラウザソースURLを確認
- `images/mouse.png` があるか確認
- 8766番ポートを他のアプリが使用していないか確認
- OBSブラウザソースのキャッシュ更新を試す

詳しい操作説明は配布ZIP内の `README.txt` を参照してください。

## 注意事項

- 配布元を確認できない実行ファイルは実行しないでください。未署名EXEではWindowsの警告が表示される場合があります。
- ゲームやOBSのアップデート、PC環境により動作が異なる場合があります。
- 本ツールはゲームの公式機能ではありません。使用するゲームや配信サービスの規約をご確認ください。
